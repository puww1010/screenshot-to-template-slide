# 用户的常用说法 → 对应规则

规则本身以 SKILL.md 为准，这里只做"听懂说法 → 找到章节"的映射。"怎么处理"一栏写着"见 §x"的，按 SKILL.md 那一节做；其余几条是 SKILL.md 里没有的补充做法。

| 用户怎么说 | 意思 | 怎么处理 |
|---|---|---|
| "原图 + slide + 描述" | 第一张是原图，第二张是参考 slide，再附讲稿 | 见 §0、§2.1 |
| "原图有了，没有参考 slide" | 只有原图和讲稿 | 照常做，参考图那一项不用管 |
| "不能照搬它的也不要利用它的内容和图标" | 参考 slide 只能借风格 | 见 §0、§2.4 |
| "不要改动模版的任何格式、logo 和颜色" | 模版保持原样 | 见 §2.3 |
| "以 xxx.pptx 为模版，上个 slide 已经给你了" | 沿用之前的模版 | 见 §1 第 1 条 |
| "用 slide-maker / ppt-master 这个 skill" | 指的就是本 skill | 见 §0 |
| "内容设计必须图文并茂，贴近描述，不要随意编撰" | 每页都要有插图，不加原图以外的文字 | 见 §2.4、§2.1 |
| "描述作为参考，不要出现在正文里" | 讲稿不能上页面 | 见 §2.1、§3 第 6 步 |
| "不需要按原图生成，可以根据描述自己规划，参考 slide 样式" | 例外：可以按讲稿设计 | 见 §2.1 的"例外" |
| "不要更改原图结构，完全按照截图来做" | 结构要和原图一致 | 见 §2.2 |
| "保持截图的标题以及标题下方的字体描述不变" | 原图文字逐字保留 | 见 §2.1 |
| "把 xxx 也表述出来" | 原图里有内容被漏了 | 补齐，并更新"逐条抄文字清单"这一步 |
| "插图上方需要重新设计编辑一下" | 插图不够好 | 只重做插图部分，往更统一、更专业、讲得清楚故事的方向改，其余不动 |
| "右上角部分的描述字体和颜色改成一致" | 只修这一处的一致性 | 见 §4 |
| "字体再专业一点、更适合演讲" | 统一字体 | 默认改成模版标题字体，问一句改动范围 |
| "需要方案 A，再优化图示和版面排序，目的引人入胜" | 定下方案后精修 | 按逻辑重排成编号段落，升级插图，突出收尾 |
| "做好以后保存到 /路径" | 指定交付位置 | 见 §1 第 2 条 |
| "后续直接给截图就可以开做了吗" | 想要零追问 | 见 §1：可以，但讲稿必须一起给 |
| "做一张来看看" | 先出一版看效果 | 见 §2.4"每页只出一个方向" |
