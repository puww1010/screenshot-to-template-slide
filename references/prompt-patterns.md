# 用户的常用说法 → 怎么做

| 用户怎么说 | 意思 | 怎么处理 |
|---|---|---|
| "原图 + slide + 描述" | 第一张是原图，第二张是参考 slide，再附讲稿 | 文字照原图；风格可以参考 slide，但不能照搬；讲稿只拿来理解 |
| "原图有了，没有参考 slide" | 只有原图和讲稿 | 照常做，参考图那一项不用管 |
| "不能照搬它的也不要利用它的内容和图标" | 参考 slide 只能借风格 | 图标全部用原生形状重画，不复制参考 slide 的内容 |
| "不要改动模版的任何格式、logo 和颜色" | 模版保持原样 | 只改 slide 层；交付前和模版逐文件比对 |
| "以 xxx.pptx 为模版，上个 slide 已经给你了" | 沿用之前的模版 | 在 uploads 里找；新会话找不到就向用户要 |
| "用 slide-maker / ppt-master 这个 skill" | 指的就是本 skill | 说明一句"该名称不存在，改用本 skill"，然后直接开做 |
| "内容设计必须图文并茂，贴近描述，不要随意编撰" | 每页都要有插图，不加原图以外的文字 | 必须画原生插图；文字逐字取自原图 |
| "描述作为参考，不要出现在正文里" | 讲稿不能上页面 | 页面文字和原图逐条核对 |
| "不需要按原图生成，可以根据描述自己规划，参考 slide 样式" | 例外：可以按讲稿设计 | 用讲稿内容排版，只压缩措辞、不添加新内容；只对这一页有效 |
| "不要更改原图结构，完全按照截图来做" | 结构要和原图一致 | 恢复原图的分区和顺序，只换视觉风格 |
| "保持截图的标题以及标题下方的字体描述不变" | 原图文字逐字保留 | 恢复原标题、副标题和原框内的文字 |
| "把 xxx 也表述出来" | 原图里有内容被漏了 | 补齐，并更新"逐条抄文字清单"这一步 |
| "插图上方需要重新设计编辑一下" | 插图不够好 | 只重做插图部分，往更统一、更专业、讲得清楚故事的方向改，其余不动 |
| "右上角部分的描述字体和颜色改成一致" | 只修这一处的一致性 | 只改指定的地方 |
| "字体再专业一点、更适合演讲" | 统一字体 | 默认改成模版标题字体，问一句改动范围 |
| "需要方案 A，再优化图示和版面排序，目的引人入胜" | 定下方案后精修 | 按逻辑重排成编号段落，升级插图，突出收尾 |
| "做好以后保存到 /路径" | 指定交付位置 | 用 request_cowork_directory 挂载这个路径，之后都保存到这里 |
| "后续直接给截图就可以开做了吗" | 想要零追问 | 可以，但讲稿必须一起给；系列开头确认一次默认设置 |
| "做一张来看看" | 先出一版看效果 | 做一页交付，等反馈 |
