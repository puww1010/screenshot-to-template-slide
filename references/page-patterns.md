# 页型结构参考

画布 10" × 5.625"（模版是别的尺寸时，下面的坐标和字号都要按 build_slide.py 提示的倍数放大）；常用安全区为 x 0.5–9.5，y 0.95–5.2。标题占位符继承版式的位置：TITLE_ONLY 版式大约在 0.34, 0.25, 9.32 × 0.63。下面每个页型都是真实交付过的版本，坐标单位是英寸。

## 1. 内容页通用骨架
- 标题：`title_ph('…')`，继承版式。
- 副标题：`text(.5,.8,9,.24)`，11pt dk2。两句话的副标题按句分行，避免末尾只剩一个词单独掉到下一行。
- kicker 小标题：9pt 粗体，dk2 或 accent1，`spc=100`。可能折成两行时，提前给它留出两行的高度。

## 2. 大数字 + 对比（例：关键指标 / 时间对比）
- 一排 3 个数字卡片，用箭头串起来，最后接一张实心 accent1 的结论卡。卡片结构是：上方徽章图标（solid）+ 粗体标签，中间 26pt accent1 大数字，下方 9pt 说明。
- 时间对比条：按天数比例画的横条，用 lt2 SOFT 和 dk2 两段表示，段内文字分两行（粗体数字 / 说明）。数字和单位要用不断行空格连起来。

## 3. 上下结构：原理示意 + "But it falls short"
- 顶部：kicker → 正文 → 横向示意图，例如 Attacker → Exploit 红虚线 → ✕ → 黑色防火墙设备 → 绿色箭头 → IT/Cloud/OT 三个绿框，下方配 "Networks Protected"。
- 中间一行：accent1 粗体 kicker 和斜体说明放在同一段里。
- 底部：3 张并排卡片，每张是图标、标题、斜体副标题、大数字、说明。标题统一 11pt，保证不折行。

## 4. How it works 标签页（系列中多页共用）
- `tabs(['Collect','Build','Deliver'], active=k)`，放在 y 1.12 处，高度 0.3。整个系列用同一组标签，只切换高亮的那一项。
- 步骤卡片：宽 1.54–1.8，间距 0.22–0.3，间隙中心放 `chevron`；圆形徽章（accent1 TINT 填充 + accent1 描边）里放图标，标题 10.5pt，说明 8.5pt，都居中。
- 分组框：用 accent1 10% 底色和 1.25pt 描边，把若干卡片框在一起，底部写分组名（例："Gateway (on-prem or cloud)"）。
- 绿色的"通过/放行"卡片：填充 `accent4` 加 lumMod 10%/lumOff 90%，描边 accent4。
- 横幅：accent1 10% 底色和 1pt 描边，左边一个徽章，粗体关键词加普通文字放在同一段。
- 收尾说明框：lt2 SOFT 底，左边绿色对勾圆圈。

## 5. 插画型流程页（原图以插画为主）
- 用一块浅色舞台把内容框起来：`shape(.5,1.0,9,3.9,'roundRect', fill accent1 10%)`。
- 4 张白卡带阴影（`shadow()`），参数为 cw 1.8、cg 0.53、y 2.48、h 0.92，卡片之间用 accent1 箭头连接。需要强调的那张卡片加 accent1 1.5pt 描边，标题也改成 accent1。
- 每张卡上下各配一组插画，用 slidekit 的部件，元素和原图一一对应。
- 循环箭头：在两张卡之间上下各画一条三次贝塞尔弧线，弧线顶点放 AI 芯片徽章。

## 6. 章节分隔页（原图带大号数字 1-5）
- 版式：`--layout "<模版里的 Section Divider 版式名>"`（用 list_layouts.py 查）。
- `stage_card(1.5,.5,7.0,1.55)`：白色卡片带阴影，插图都画在卡片里。不要直接画在条纹或渐变背景上，否则会显得杂乱。
- 插图元素用白底黑描边，强调部分用 accent1。人物用**实心剪影**，不用火柴人。
- 标题：`title_ph('…')`，继承版式（例：白色 36pt 居中）。
- 副标题：`text(.8,3.2,8.4,.4)`，18pt lt1 居中。
- `progress_meter(n, 5)`：放在 y 4.15。

## 7. 轮辐图 / 部署无处不在
- 中心枢纽：直径 1.24 的圆，accent1 2pt 描边，外面一圈 TINT 光晕，里面放保险库和盾牌，下方配两行 8.5pt 标签。
- 四张环境卡：宽 2.45、高 0.92，放在四角，用阴影代替描边；卡片左侧是灰底圆形图标，右侧是名称加说明；右上角放一个 `mini_badge`（✕ 或 ✓）表示状态。
- 右侧面板讲"连锁反应"：步骤 ① ② 之间用下箭头连接，最后用大字收尾。

## 8. 引语气泡收尾
- `wedgeRoundRectCallout`（adj1 30000、adj2 68000），后面叠一个偏移 (+.09, +.09) 的 accent1 同形状做错位阴影；左上角放 54pt accent1 大引号，正文 24pt，关键词用 `hl_run`（accent2 荧光高亮）。

## 9. 居中问句 / 封面
- 在本页覆盖标题占位符：`title_ph(t, 1.55,1.12,6.9,1.85, sz=24, algn='ctr')`，问句里的关键词高亮。
- 背后放一个 300pt 的 "?"，颜色用 accent1 10%，做装饰。
- 封面：标题居中 36pt；下面是黑框白底的插图卡，带 accent1 偏移阴影，左上角一个圆点。

## 10. 议程页
- 5 张竖向卡片：标题 13pt 粗体，上方是 01–05 编号，中间一个 solid 徽章，底部是逐张递增的 5 格进度条。
- 卡片之间的 › 圆点必须在**所有卡片画完之后**再添加，否则会被后面的卡片遮住。
