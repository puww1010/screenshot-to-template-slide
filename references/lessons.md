# QA 清单与踩过的坑

## 每页必查（看 6% 压力渲染图）
1. **文字溢出**或贴到卡片边缘：最常见。处理办法依次是：加高或加宽容器 → 整组同级元素一起缩小 → 改成上下分区，给文字栏更多宽度。
2. **折行问题**：
   - 一个词单独掉到下一行：按句子手动分行，比如把副标题拆成两段。
   - 数字和单位被拆开（如 "145+ / days"）：加宽文本框，并在两者之间用不断行空格。
   - 带连字符的词在连字符处断开（on-box、X-Series）：把连字符换成 U+2011 不断行连字符。
3. **重叠**：小标题压到正文、副标题撞到说明、箭头压到图标、插图冲出卡片边缘。
4. **图层顺序**：连接用的 ›、箭头、徽章要在卡片之后添加，否则会被盖住。
5. **同级样式**：并列条目的字号、字重、颜色必须一致。
6. **留白和平衡**：插图整体偏向一侧时，把整组平移（用 group 改 off）；底部留白过大时，把舞台缩短。
7. **对照原图核对文字**：不能少，也不能多出讲稿里的句子。

## 技术坑
- **字体**：模版标题字体可能是 Helvetica Neue，而沙盒里没装，LibreOffice 会换成 DejaVu，看起来偏宽，这不代表有问题。build_slide.py 会把它映射成 Liberation Sans，再放大 6% 字号做压力测试，近似 HN 比 Arial 宽的情况。在 Windows 上没有 HN 时会回退到 Arial，交付时要提醒用户。
- **旋转**：整体旋转一个组合件（比如试管连同里面的液体）时，要先打成一组，再给 group 的 xfrm 加 rot。不能把子形状各自旋转，否则会错位。
- **整组缩放**：把 group 的 ext 改小、chOff/chExt 保持不变（rocket 就是这样缩进小徽章里的）。
- **绿色底**：accent4 当底色时用 lumMod 10%/lumOff 90%。20/80 会太艳。
- **高亮**：`a:highlight` 填 accent2，需要 Office 2019 或 365 才能显示，交付时要提醒。
- **zip 打包**：用 `zip -qXDr`，不写目录条目，不然和模版逐文件比对时会多出一堆差异。
- **sed 批量替换**：短模式（比如 `t-`）会误伤路径里的同名片段，要用带上下文的精确模式。
- **python -I**：-I 模式下不会把脚本所在目录加进 sys.path，导入同目录模块要自己 `sys.path.insert`。
- **重复的 shape id**：每次构建前先把 `C.i` 重置，生成新页时不要复用旧 id。
- **用户在 PowerPoint 里另存过**：文件体积会变化。改字体这类批量修改要直接在用户的副本上做，保留用户自己的改动。
- **pptx skill（可选）**：Claude 沙盒里在 `/sessions/*/mnt/.claude/skills/pptx`，在那里直接调 `soffice` 可能会卡住，要用它的 `scripts/office/soffice.py`。没有这个 skill 时，build_slide.py 会用独立的 LibreOffice profile 直接渲染（超时 240 秒），也可以用 `--pptx-skill none` 强制走内置流程。

## LibreOffice 和 PowerPoint 的差异
QA 渲染用的是 LibreOffice，下面这些地方它和 PowerPoint 不一样，渲染图看着没问题不代表 PowerPoint 里没问题：
- **行距、段距、字号的异常值**：LibreOffice 会自动纠正，PowerPoint 照原值排版。真实案例：行距写成 `spcPct val="120"`（应为 120000），PowerPoint 里整段文字叠成一行，看起来像重影。现在 build_slide.py 的 lint 会拦截这类问题，slidekit.para 的 lnpct 也改成按百分比传参。
- **中文断行**：两边的避头尾规则不同，同一段话的折行位置可能不一样。并列卡片里最好用 `<a:br>` 手动断行，不要依赖自动折行刚好落在好位置。
- **字体替换**：沙盒里没有模版字体时，压力渲染会用 Liberation Sans、Noto Sans CJK SC 来近似，宽度只是接近。苹方只有 macOS 有，Windows 上会被替换；Figtree 这类网络字体，放映的电脑不一定装了（脚本会给 `[NOTE] font`）。
- **预设图形**：cloud 等形状的描边在 LibreOffice 里可能出现缺口，PowerPoint 里是正常的；需要描边时优先用阴影代替。
- **文本框自动缩放（autofit）**：slidekit 默认 noAutofit，不要依赖 PowerPoint 的自动缩字。

## 视觉经验
- 章节页插图直接画在条纹或渐变背景上会显得乱，放进白色阴影卡片里就专业很多。
- 人物用实心剪影，不用火柴人。
- 卡片描边在 LibreOffice 里可能渲染出缺口，换成柔和的阴影更稳定。
- 插画类原图要按原图元素重画，比如服务器、保险库、盾牌、齿轮、代码栈、火箭、大门，但不要照搬原图的画法。
